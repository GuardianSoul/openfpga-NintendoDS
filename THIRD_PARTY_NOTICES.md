### This project's own files

Everything else in `rtl/` and `sw/` was written for this core, including the
ARM9 and ARM7 CPUs, memory system, 2D and 3D engines, sound, DMA, timers,
cartridge, SPI, RTC and WiFi stand-in, the boot program `sw/boot` and the
shell firmware `sw/scpu`. These files are GPL-3.0-or-later. Files whose SPDX
header says MIT (most of `rtl/pocket`, `rtl/mem` and `rtl/probe`) are MIT.

`sw/boot/key1.s` was written from GBATEK's description. It reads the KEY1
table from the user's own ARM7 BIOS at run time; no BIOS data is included.

## Behaviour reference

The core was designed to behave as the DS does, and was checked against
[melonDS](https://github.com/melonDS-emu/melonDS) (copyright the melonDS
team, GPL-3.0-or-later). Many blocks were written to match melonDS's
behaviour closely. No melonDS source is compiled into the bitstream, but
because of that closeness the core is GPL-3.0-or-later, the same license.
